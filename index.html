Sprints

https://2026.djangocon.us/sprints and #sprints on Slack
Good news! We have sprints this thursday and friday. Sprints are collaboration events where people work together on open-source for a full day. You'll have the opportunity to contribute to number of projects, including Django.
On thursday morning we'll have presentations on how to contribute to Django and how to do a code review for Django.
In the afternoon, we're going to have a review session of the new features board for Django.
If you've got questions or want to get started early, check out the #sprints channel.

Djangonaut Space

https://djangonaut.space Accepting applications now!
If you're not going to be at sprints or would like a little more assistance getting started.
Djangonaut Space is a 8 week contributor mentorship program. It's full of space puns and super welcoming people.
We'll match you with community mentors who will guide and support you as you learn to contribute to an open source project like Django.
We expect people to spend about 5 hours a week during this program and we're currently accepting applications.
This next session launches October 12th

Chat with the DSF booth

If you're not interested in code or documentation contributions and are more focused on the community and marketing aspects, stop by the DSF booth and ask how you can get involved.
Someone from the board or steering council should be around to answer questions and help you find your path to contributing back.
